# PLE-635: the Oculus Go's video decoder and its Qualcomm low-latency switch

Which hardware decoder Pleikkari uses on the Oculus Go, which low-latency options its Android 7.1
media stack accepts from an app, and what they do to decode time. The consumer is PLE-601
(Oculus Go latency rounds), which A/Bs the result.

## Device and build

* Oculus Go, serial `1KWPH802EW8203`, Wi-Fi ADB `192.168.1.202:5555`, `ro.product.device=pacific`,
  `ro.board.platform=msm8996` (Snapdragon 821), Android 7.1.1 / API 25, fingerprint
  `oculus/vr_pacific/pacific:7.1.1/NGI77B/20008400174500000:user/release-keys`.
* PS5-466 (`192.168.1.164`), reachable per `scripts/dev/ps5-discover.py` before the runs.
* Stream: the app's default profile, 1920x1080 at 60 fps, H.265, target 14.6 Mbps (measured
  10-11 Mbps).

## What the Go exposes

`/system/etc/media_codecs.xml` lists the hardware decoders first, then includes
`media_codecs_google_video.xml`:

| Decoder | Size | Blocks/s | Frame rate | Notes |
|---|---|---|---|---|
| `OMX.qcom.video.decoder.avc` | 64x64-4096x2160 | 1,958,400 | 1-240 | `adaptive-playback`; `vt-low-latency` limit = 1; `vt-max-level` 52 |
| `OMX.qcom.video.decoder.hevc` | 64x64-4096x2160 | 1,958,400 | 1-240 | `adaptive-playback` |
| `OMX.qcom.video.decoder.{avc,hevc}.secure` | | 979,200 | | `secure-playback` required |
| `OMX.google.h264.decoder`, `OMX.google.hevc.decoder` | | | | software |

`media_codecs_performance.xml` measures the Qualcomm HEVC decoder at 216-249 fps for 1920x1080,
and the AVC decoder at 170-191 fps for 1920x1088. There are no `c2.*` codecs on 7.1.
`dumpsys media.player` lists no codec state, and `dumpsys media.codec` is empty on this build.

**What Pleikkari picks:** `AMediaCodec_createDecoderByType("video/hevc")` gives
`OMX.qcom.video.decoder.hevc`. Logcat for every live stream shows
`OMXMaster: makeComponentInstance(OMX.qcom.video.decoder.hevc) in mediacodec process`, then
`MediaCodec: [OMX.qcom.video.decoder.hevc]`. `AMediaCodec_getName` is API 28, so the session log
can only say `Video decoder component: unknown (API < 28)`. The first match for `video/avc` in
the same list is `OMX.qcom.video.decoder.avc`, but no H.264 stream was run live.

Before PLE-635, every Go session configured tier 3 plus the default-path
`operating-rate=960 frame-rate=60` (six operator sessions on 2026-09-27, all the same). The
existing `vendor.qti-ext-dec-picture-order.enable` key never fires on the Go, because it is gated
on a `c2.qti.` component name.

## Which keys reach the decoder on Android 7.1

Read from the Go's own binaries: `/system/lib64/libstagefright.so` (ACodec),
`/vendor/lib64/libavenhancements.so` (Qualcomm's `ExtendedACodec`, which runs in the app process
and logs `ExtendedACodec: setupVideoDecoder()` on every stream start) and
`/vendor/lib{,64}/libOmxVdec.so` (the OMX component in the `media.codec` process). They were
disassembled with the NDK `llvm-objdump`.

| MediaFormat key | Reaches the decoder? | Effect |
|---|---|---|
| `low-latency` (API 30) | no | ACodec 7.1 has no such key; it is silently ignored |
| `vendor.qti-ext-dec-picture-order.enable`, `vendor.qti-ext-dec-low-latency.enable` | no | there is no `vendor.*` extension mapping before Android 8 |
| `frame-rate` | yes | input port frame rate |
| `operating-rate` | yes | `OMX_IndexConfigOperatingRate` → `V4L2_CID_MPEG_VIDC_VIDEO_OPERATING_RATE` (Q16). The driver accepted both 240 and today's 960 (no `codec does not support config operating rate` and no `Failed to set operating rate` in logcat) |
| `priority` | yes | `OMX_IndexConfigPriority` → `V4L2_CID_MPEG_VIDC_VIDEO_PRIORITY`; 0 = realtime |
| `android._num-output-buffers` | yes, but overwritten | ACodec's `setPortBufferNum`, but with a Surface, `configureOutputBuffersFromNativeWindow` recomputes the count from `nBufferCountMin` plus the window's min-undequeued count. Not a knob when decoding to a Surface |
| **`vt-low-latency`** | **yes** | `ExtendedACodec::setupVideoDecoder` (any `OMX.qcom.*` component, any codec) calls `getExtensionIndex("OMX.QTI.index.param.video.LowLatency")` and sets it with `bEnable = value != 0`. The vdec maps that name to index `0x7F00005B`, whose `set_parameter` case logs `Enabling DECODE order`, turns timestamp reordering off and sets V4L2 control `0x992007` to 1 (output order = decode). A failed get or set returns the error and fails the whole configure |
| `thumbnail-mode` | yes | `OMX.QCOM.index.param.video.SyncFrameDecodingMode`: sync frames only. Unusable for streaming |
| `use-arbitrary-mode`, `smooth-streaming`, `prefer-adaptive-playback`, `vpp-*` | yes | not latency knobs (frame-by-frame is already the default: `Decoder will be in frame by frame mode`) |

The vdec also has `OMX_QcomIndexParamVideoDecoderPictureOrder`, but nothing on the 7.1 path
calls it. The Go's `media_codecs.xml` advertises `vt-low-latency` only for the AVC decoder. The
code path does not check the codec, so it applies to both.

## The setting

`stream_decoder_qcom_vt_low_latency` (developer settings: "Qualcomm low-latency decode (Oculus
Go)"). It defaults to off, and it is shown and applied only when `Build.DEVICE == "pacific"`.
When on, the decoder format gets `vt-low-latency=1` at every configure tier, so frames come out in
decode order with no display-order hold. The PS5 stream has no B-frames, so decode order is
display order. If configure fails with the key, the tiers are retried without it. The session
log says `Qualcomm VT low-latency decode requested` and
`AMediaCodec_configure() succeeded ... with vt-low-latency`. The diagnostics overlay shows the
flag `qcom-vt`.

The `Feedback stats:` line (with `stream_feedback_stats_log=true`) now ends with
` | decode mean_ms X p95_ms Y`. That is the per-window mean and p95 of input-queue to
output-dequeue time, so the session log alone carries the decode time.

## Measured on the Go (live PS5-466 stream)

Two 45 s streams on 2026-09-27 at 01:04-01:06 UTC, back to back, on build
`app-ple635-v1.apk` (SHA-256 `e1c843f1…`). The first five stats windows are skipped. The build
had the first version of this ticket's setting: an operating-rate profile (`operating-rate=240`,
the decoder's advertised capacity at 1080p, plus `priority=0`) instead of today's default path
(`operating-rate=960 frame-rate=60`).

| Arm | Decoder config | Windows | Frames | Decode mean | Window means | Window p95 (median / max) |
|---|---|---|---|---|---|---|
| A (today) | tier 3, `frame-rate=60 operating-rate=960` | 37 | 2225 (60.0 fps) | **6.88 ms** | 6.37-7.64 ms | 9.36 / 11.71 ms |
| B | tier 3, `frame-rate=60 operating-rate=240 priority=0` | 34 | 2037 (59.8 fps) | **6.99 ms** | 6.49-7.85 ms | 9.79 / 12.47 ms |

No input or presenter drops occurred in either arm. The operating-rate profile changed nothing,
because today's 960 is already accepted, and priority has its own setting
(`stream_decoder_realtime_priority`). So the profile was replaced by `vt-low-latency`, the one
Qualcomm low-latency option that 7.1 lets an app reach. **The `vt-low-latency` off/on A/B has not
run yet.** From 01:10 UTC the Go was reserved end to end by `resource:go` worker runs
(PLE-650-654), and PLE-635's per-session lease requests never got it again.

## Method notes for PLE-601

* **Starting a stream headlessly on the Oculus TV panel is not solved.** Android 7.1's
  `dumpsys activity <pkg>` searches only the focused stack, which is vrshell's, so it answers
  "no activities match" for an app hosted in Oculus TV's ActivityView. `uiautomator` and
  `input tap` reach only display 0. A TAB/ENTER walk to `playButton` therefore has to be blind,
  and on 7.1 focus order is geometric: the toolbar comes first, then the quality-preset buttons,
  whose ENTER rewrites stream prefs.
* **Display 0 works:**
  1. `am force-stop`, and check that no `fi.madekivi.pleikkari/` ActivityRecord exists on any
     display (an `am start` of a panel-hosted activity crashes SystemUI, PLE-600).
  2. Write the prefs.
  3. `am start -W -n fi.madekivi.pleikkari/.main.MainActivity`.
  4. `uiautomator dump`, then `input tap` on the enabled `playButton` bounds.
  5. Wait for `StreamActivity`.
  6. End the stream with `am force-stop`. A BACK on display 0 arms vrshell's
     `systemux://dialog/exit`, which swallows later launches until one more BACK.

  The decoder, its format and the decode-time metric are the same as on the TV panel. What
  differs is the Surface's consumer.
* A pending `systemux://dialog/exit` shows in logcat as
  `DialogController: showDialog systemux://dialog/exit` right after a launch. One BACK clears it.

The pre-PLE-635 Go app state (prefs, databases, `base.apk`, taken 01:04 UTC) is kept in
`~/.config/pleikkari/backups/go-ple635-before-20260927T0104Z/` on CT950.

Artifacts (gitignored, in the PLE-635 worktree): `build/ple635/survey/` (codec XMLs, getprop,
pulled libraries, disassembly), `build/ple635/run5/` (session logs, logcat, prefs per arm),
`build/ple635/decode_stats.py` (the table above), `build/ple635/go-ab.sh` (the session script).

## Appendix: the session script

It runs under the Go lease and is deadline-aware, so a long FIFO wait can never cut a step in
half. Example for the pending `vt-low-latency` A/B (HEVC, then H.264):

```
export BACKUP=<snapshot dir> DEADLINE=$(( $(date +%s) + 580 )) SECS=45
scripts/dev/device.py run --resource go PLE-N -- bash go-ab.sh <out> setup \
    ensure <apk> arm0 C-hevc-off "" arm0 D-hevc-vt "stream_decoder_qcom_vt_low_latency=true" \
    arm0 E-avc-off "stream_codec=s:h264" \
    arm0 F-avc-vt "stream_codec=s:h264,stream_decoder_qcom_vt_low_latency=true" restore
python3 decode_stats.py <out>/session-*.log
```

```bash
#!/usr/bin/env bash
# PLE-635 decoder A/B on the real Oculus Go over a live PS5-466 stream (Oculus TV panel path).
# Run under the Go lease:
#   device.py run --resource go PLE-635 -- bash build/ple635/go-ab.sh <out> <step>...
# Steps: setup | install <apk> | arm <label> <key=bool,...> | restore
#  setup    snapshot prefs, databases (cat, no tar needed) and the installed base.apk
#  install  install -r (never uninstall, never clear)
#  arm      BACK out of any stream of ours, force-stop, write snapshot prefs + stats log +
#           the arm's keys, launch through vrshell (PLE-600), TAB to playButton, ENTER,
#           stream $SECS s, BACK, pull the newest session log
#  restore  force-stop, reinstall the snapshot APK, write the snapshot prefs back byte-identically
set -uo pipefail
G=192.168.1.202:5555
PKG=fi.madekivi.pleikkari
PREFS=shared_prefs/${PKG}_preferences.xml
OUT=${1:?out dir}; shift
SECS=${SECS:-70}
mkdir -p "$OUT"
LOG="$OUT/session.log"
BACKUP=${BACKUP:-$OUT/backup}
a() { echo "$(date -u +%T) adb $*" >>"$LOG"; adb -s $G "$@"; }
say() { echo "$(date -u +%T) $*" | tee -a "$LOG"; }
resumed() { a shell 'dumpsys activity activities | grep mResumedActivity' | tr -d '\r' | grep -o "$PKG/[^ ]*" | head -1; }
focus() { a shell 'dumpsys window windows | grep mCurrentFocus' | tr -d '\r'; }

LOGCAT_PID=
start_logcat() {
	echo "$(date -u +%T) adb logcat -v threadtime -T 1 (background, bounded)" >>"$LOG"
	timeout $((SECS + 150)) adb -s $G logcat -v threadtime -T 1 > "$OUT/logcat-$1.txt" 2>/dev/null &
	LOGCAT_PID=$!
}
stop_logcat() { [ -n "$LOGCAT_PID" ] && kill "$LOGCAT_PID" 2>/dev/null; LOGCAT_PID=; }
trap stop_logcat EXIT

stop_our_stream() {
	local cur
	cur=$(resumed)
	case "$cur" in *Stream*)
		say "BACK out of $cur"
		a shell input keyevent KEYCODE_BACK
		for _ in $(seq 1 15); do cur=$(resumed); case "$cur" in *Stream*) sleep 1 ;; *) break ;; esac; done
		;;
	esac
}

write_prefs() { # <file>
	a push "$1" /data/local/tmp/ple635_prefs.xml >/dev/null
	a shell "chmod 644 /data/local/tmp/ple635_prefs.xml; run-as $PKG cp /data/local/tmp/ple635_prefs.xml $PREFS; rm -f /data/local/tmp/ple635_prefs.xml"
	a exec-out run-as $PKG cat $PREFS > "$OUT/prefs-readback.xml"
	cmp -s "$1" "$OUT/prefs-readback.xml" || { say "prefs readback mismatch for $1"; return 1; }
}

step_setup() {
	local cur
	if [ -s "$BACKUP/base.apk" ]; then say "backup in $BACKUP exists; keeping the first snapshot"; return 0; fi
	cur=$(resumed)
	case "$cur" in *Stream*) say "abort: a stream is live ($cur), not ours"; exit 2 ;; esac
	mkdir -p "$BACKUP/databases"
	a exec-out run-as $PKG cat $PREFS > "$BACKUP/prefs.xml"
	[ -s "$BACKUP/prefs.xml" ] || { say "abort: empty prefs backup"; exit 2; }
	for f in chiaki chiaki-wal chiaki-shm; do
		a exec-out run-as $PKG cat databases/$f > "$BACKUP/databases/$f" 2>/dev/null
		[ -s "$BACKUP/databases/$f" ] || rm -f "$BACKUP/databases/$f"
	done
	local path
	path=$(a shell pm path $PKG | tr -d '\r' | sed -n 's/^package://p' | head -1)
	a pull "$path" "$BACKUP/base.apk" >/dev/null || { say "abort: cannot pull $path"; exit 2; }
	a shell dumpsys package $PKG | tr -d '\r' | grep -E "versionCode|lastUpdateTime" > "$BACKUP/package.txt"
	say "backup: prefs $(wc -c < "$BACKUP/prefs.xml") B, db $(ls "$BACKUP/databases" | tr '\n' ' '), apk $(wc -c < "$BACKUP/base.apk") B; $(tr '\n' ' ' < "$BACKUP/package.txt")"
	a shell getprop ro.build.fingerprint > "$OUT/fingerprint.txt"
}

step_install() {
	stop_our_stream
	a install -r "$1" 2>&1 | tail -1 | tee -a "$LOG"
	a shell dumpsys package $PKG | tr -d '\r' | grep -E "versionCode|lastUpdateTime" | tee -a "$LOG"
}

arm_prefs() { # <label> <key=bool,...> -> $OUT/prefs-<label>.xml
	python3 - "$BACKUP/prefs.xml" "$OUT/prefs-$1.xml" "stream_feedback_stats_log=true,stream_go_vr_enabled=false,$2" <<'EOF'
import re, sys
src, dst, spec = sys.argv[1:]
text = open(src).read()
for item in filter(None, spec.split(",")):
    key, value = item.split("=")
    text = re.sub(r'\s*<boolean name="%s" value="[a-z]+" />' % re.escape(key), "", text)
    text = re.sub(r'\s*<string name="%s">[^<]*</string>' % re.escape(key), "", text)
    if value.startswith("s:"):
        text = text.replace("</map>", '    <string name="%s">%s</string>\n</map>' % (key, value[2:]))
    else:
        text = text.replace("</map>", '    <boolean name="%s" value="%s" />\n</map>' % (key, value))
open(dst, "w").write(text)
EOF
}

step_arm() { # <label> <spec>
	local label=$1 spec=$2 cur
	say "=== arm $label ($spec)"
	stop_our_stream
	cur=$(resumed)
	case "$cur" in *Stream*) say "abort: a stream is still live ($cur)"; exit 2 ;; esac
	arm_prefs "$label" "$spec"
	a shell am force-stop $PKG
	sleep 1
	write_prefs "$OUT/prefs-$label.xml" || exit 3
	start_logcat "$label"
	local attempt
	cur=
	local seen
	for attempt in 1 2 3; do
		seen=$(wc -l < "$OUT/logcat-$label.txt")
		a shell am start -n com.oculus.vrshell/.MainActivity -d apk://com.oculus.tv -e uri $PKG/.main.MainActivity >>"$LOG" 2>&1
		for _ in $(seq 1 12); do cur=$(resumed); [ -n "$cur" ] && break 2; sleep 1; done
		# PLE-600: a pending systemux://dialog/exit swallows every launch until one BACK cancels it.
		if tail -n +$((seen + 1)) "$OUT/logcat-$label.txt" | grep -q 'showDialog systemux://dialog/exit\|New dialog: type: 12, uri "systemux://dialog/exit"'; then
			say "launch $attempt swallowed by the vrshell exit dialog; one BACK cancels it (PLE-600)"
			a shell input keyevent KEYCODE_BACK
			sleep 3
		else
			say "launch $attempt: not resumed and no exit dialog seen"
		fi
	done
	say "resumed after launch: ${cur:-none}; $(focus)"
	[ -n "$cur" ] || { stop_logcat; return 4; }
	sleep 3
	local pressed=0 i n pb foc
	for i in $(seq 1 25); do
		a shell dumpsys activity $PKG | tr -d '\r' > "$OUT/hier-$label.txt"
		n=$(grep -c 'app:id/playButton' "$OUT/hier-$label.txt")
		[ "$n" -eq 1 ] || { say "playButton count $n"; stop_logcat; return 5; }
		pb=$(grep 'app:id/playButton' "$OUT/hier-$label.txt" | head -1)
		if echo "$pb" | grep -qE '\{[0-9a-f]+ [^ ]+ .F'; then
			say "playButton focused after $i dumps; ENTER"
			a shell input keyevent KEYCODE_ENTER
			pressed=1
			break
		fi
		foc=$(grep -E '\{[0-9a-f]+ [^ ]+ .F' "$OUT/hier-$label.txt" | tail -1 | sed 's/^ *//' | cut -c1-120)
		echo "$(date -u +%T) focus: ${foc:-none}; TAB" >> "$LOG"
		a shell input keyevent KEYCODE_TAB
		sleep 0.7
	done
	[ "$pressed" = 1 ] || { say "never focused playButton"; stop_logcat; return 6; }
	for _ in $(seq 1 45); do cur=$(resumed); case "$cur" in *Stream*) break ;; esac; sleep 1; done
	say "resumed after ENTER: ${cur:-none}"
	case "$cur" in *Stream*) ;; *) stop_logcat; return 7 ;; esac
	# No key is sent while the stream is up except the final BACK (not a PS5 button).
	sleep "$SECS"
	cur=$(resumed)
	say "after ${SECS}s: ${cur:-none}; Feedback stats lines so far: $(grep -c 'Feedback stats' "$OUT/logcat-$label.txt")"
	stop_our_stream
	sleep 2
	stop_logcat
	local sess
	sess=$(a shell "run-as $PKG ls -t files/session_logs" | tr -d '\r' | head -1)
	a exec-out run-as $PKG cat "files/session_logs/$sess" > "$OUT/session-$label.log"
	say "session log $sess -> session-$label.log ($(wc -c < "$OUT/session-$label.log") B)"
	grep -E "Video decoder component|operating-rate|priority|Qualcomm OMX|AMediaCodec_configure|Switched to profile" "$OUT/session-$label.log" | sed 's/^/    /' | tee -a "$LOG"
}

# Display-0 variant: Android 7.1's `dumpsys activity <pkg>` only searches the focused stack
# (vrshell's), so the TV-panel ActivityView's view tree cannot be read and playButton cannot be
# focused on purpose. On display 0 uiautomator and input tap work. Never start while any activity
# of ours exists (PLE-600: am start of a panel-hosted activity crashes SystemUI), never send BACK
# on display 0 (it arms vrshell's exit dialog), end the stream with force-stop.
ours_anywhere() { a shell 'dumpsys activity activities' | tr -d '\r' | grep -c "ActivityRecord{[^}]* $PKG/"; }
step_arm0() { # <label> <spec>
	local label=$1 spec=$2 cur n out
	say "=== arm $label on display 0 ($spec)"
	cur=$(resumed)
	case "$cur" in *Stream*) say "abort: a stream is live ($cur)"; exit 2 ;; esac
	arm_prefs "$label" "$spec"
	a shell am force-stop $PKG
	sleep 2
	n=$(ours_anywhere)
	[ "$n" = 0 ] || { say "abort: $n activity records of ours still exist; not starting on display 0"; exit 2; }
	write_prefs "$OUT/prefs-$label.xml" || exit 3
	start_logcat "$label"
	out=$(a shell am start -W -n $PKG/.main.MainActivity 2>&1 | tr -d '\r')
	echo "$out" >> "$LOG"
	case "$out" in *"kept for the user"*|*Error*) say "am start refused: $(echo "$out" | tail -2 | tr '\n' ' ')"; stop_logcat; return 4 ;; esac
	local tapped=0 i node xy
	for i in $(seq 1 20); do
		sleep 1
		a shell uiautomator dump /sdcard/ple635-ui.xml >/dev/null 2>&1
		a exec-out cat /sdcard/ple635-ui.xml > "$OUT/ui-$label.xml" 2>/dev/null
		node=$(grep -o '<node [^>]*resource-id="'$PKG':id/playButton"[^>]*>' "$OUT/ui-$label.xml" | head -1)
		[ -n "$node" ] || continue
		echo "$node" | grep -q 'enabled="true"' || continue
		xy=$(echo "$node" | sed -n 's/.*bounds="\[\([0-9]*\),\([0-9]*\)\]\[\([0-9]*\),\([0-9]*\)\]".*/\1 \2 \3 \4/p' | awk '{print int(($1+$3)/2), int(($2+$4)/2)}')
		[ -n "$xy" ] || continue
		say "playButton at $xy ($(echo "$node" | grep -o 'text="[^"]*"')); tap"
		a shell input tap $xy
		tapped=1
		break
	done
	a shell rm -f /sdcard/ple635-ui.xml
	[ "$tapped" = 1 ] || { say "no enabled playButton on display 0"; stop_logcat; return 5; }
	for _ in $(seq 1 45); do cur=$(resumed); case "$cur" in *Stream*) break ;; esac; sleep 1; done
	say "resumed after tap: ${cur:-none}"
	case "$cur" in *Stream*) ;; *) stop_logcat; return 7 ;; esac
	# No input at all while the stream is up (AGENTS.md rule 12).
	sleep "$SECS"
	cur=$(resumed)
	say "after ${SECS}s: ${cur:-none}; Feedback stats lines: $(grep -c 'Feedback stats' "$OUT/logcat-$label.txt")"
	a shell am force-stop $PKG
	sleep 2
	stop_logcat
	local sess
	sess=$(a shell "run-as $PKG ls -t files/session_logs" | tr -d '\r' | head -1)
	a exec-out run-as $PKG cat "files/session_logs/$sess" > "$OUT/session-$label.log"
	say "session log $sess -> session-$label.log ($(wc -c < "$OUT/session-$label.log") B)"
	grep -E "Video decoder component|operating-rate|priority|Qualcomm OMX|AMediaCodec_configure|Switched to profile" "$OUT/session-$label.log" | sed 's/^/    /' | tee -a "$LOG"
	# The app is stopped: put the owner's prefs back between sessions.
	write_prefs "$BACKUP/prefs.xml" && say "original prefs back"
	# Let the console notice the dropped client before the next arm connects.
	sleep 12
}

step_ensure() { # <apk>: install -r only if the installed base.apk differs from ours
	local want have path
	want=$(md5sum < "$1" | cut -d' ' -f1)
	path=$(a shell pm path $PKG | tr -d '\r' | sed -n 's/^package://p' | head -1)
	have=$(a shell md5sum "$path" | tr -d '\r' | cut -d' ' -f1)
	if [ "$want" = "$have" ]; then say "installed APK is ours ($want)"; return 0; fi
	say "installed APK $have is not ours ($want): install -r"
	step_install "$1"
}

step_restore() {
	stop_our_stream
	a shell am force-stop $PKG
	a install -r "$BACKUP/base.apk" 2>&1 | tail -1 | tee -a "$LOG"
	write_prefs "$BACKUP/prefs.xml" && say "prefs restored byte-identically"
	a shell dumpsys package $PKG | tr -d '\r' | grep -E "versionCode|lastUpdateTime" | tee -a "$LOG"
	a shell run-as $PKG ls -la databases | tee -a "$LOG"
}

# DEADLINE (epoch s): a step starts only if its worst case fits before it, so a long FIFO
# wait can never cut a step in half. restore always runs if setup did (it is the promise).
DEADLINE=${DEADLINE:-$(( $(date +%s) + 3600 ))}
fits() { [ $(( $(date +%s) + $1 )) -le "$DEADLINE" ]; }
say "lease acquired; $(( DEADLINE - $(date +%s) ))s left before the deadline"
did_setup=0
did_install=0
while [ $# -gt 0 ]; do
	case "$1" in
	setup) shift; fits $(( SECS + 130 )) || { say "deferred: no time for setup+install+restore"; exit 9; }; step_setup; did_setup=1 ;;
	install) if fits 110; then step_install "$2"; did_install=1; else say "deferred install"; fi; shift 2 ;;
	ensure) if fits $(( SECS + 180 )); then step_ensure "$2" && did_install=1; else say "deferred ensure"; fi; shift 2 ;;
	arm) if [ "$did_install" = 1 ] && fits $(( SECS + 110 )); then step_arm "$2" "$3" || say "arm $2 failed rc=$?"; else say "deferred arm $2"; fi; shift 3 ;;
```

```python
#!/usr/bin/env python3
"""PLE-635: per-arm decode time from the app's session logs (`Feedback stats` decode segment).

Usage: decode_stats.py [--skip N] session-A.log [session-B.log ...]
Skips the first N stats windows (connect, first IDR). Prints per-arm window count, the
frame-weighted mean of the per-window decode means, the median and max of the per-window
p95s, received/decoded frames and drops.
"""
import re
import statistics
import sys

LINE = re.compile(
    r"Feedback stats: window (?P<window>\d+) ms video received (?P<received>\d+) decoded (?P<decoded>\d+)"
    r" dropped_input (?P<dropped_input>\d+) dropped_presenter (?P<dropped_presenter>\d+).*?"
    r"\| decode mean_ms (?P<mean>[\d.]+) p95_ms (?P<p95>[\d.]+)")
DJB = re.compile(r"Video presenter DJB .*?decode (?P<ewma>[\d.]+) ms")


def arm(path, skip):
    rows = [m.groupdict() for m in map(LINE.search, open(path, errors="replace")) if m]
    rows = [r for r in rows[skip:] if int(r["decoded"]) > 0]
    decoded = sum(int(r["decoded"]) for r in rows)
    wmean = sum(float(r["mean"]) * int(r["decoded"]) for r in rows) / decoded if decoded else float("nan")
    p95s = [float(r["p95"]) for r in rows]
    means = [float(r["mean"]) for r in rows]
    ewma = [float(m.group("ewma")) for m in map(DJB.search, open(path, errors="replace")) if m]
    return {
        "windows": len(rows),
        "decoded": decoded,
        "received": sum(int(r["received"]) for r in rows),
        "fps": decoded / (sum(int(r["window"]) for r in rows) / 1000.0) if rows else 0,
        "mean_ms": wmean,
        "window_mean_median": statistics.median(means) if means else float("nan"),
        "window_mean_min": min(means) if means else float("nan"),
        "window_mean_max": max(means) if means else float("nan"),
        "p95_median": statistics.median(p95s) if p95s else float("nan"),
        "p95_max": max(p95s) if p95s else float("nan"),
        "dropped_input_last": rows[-1]["dropped_input"] if rows else "-",
        "dropped_presenter_last": rows[-1]["dropped_presenter"] if rows else "-",
        "djb_decode_ewma_median": statistics.median(ewma) if ewma else float("nan"),
    }


def main(argv):
    skip = 5
    if argv and argv[0] == "--skip":
        skip = int(argv[1])
        argv = argv[2:]
    print(f"(first {skip} stats windows skipped)")
    for path in argv:
        s = arm(path, skip)
        print(f"{path}: windows {s['windows']} decoded {s['decoded']} ({s['fps']:.1f} fps) received {s['received']}"
              f" | decode mean {s['mean_ms']:.2f} ms (window means median {s['window_mean_median']:.2f},"
              f" range {s['window_mean_min']:.2f}-{s['window_mean_max']:.2f})"
              f" | p95 median {s['p95_median']:.2f} max {s['p95_max']:.2f} ms"
              f" | dropped_input {s['dropped_input_last']} dropped_presenter {s['dropped_presenter_last']}"
              f" | DJB decode EWMA median {s['djb_decode_ewma_median']:.2f} ms")


if __name__ == "__main__":
    main(sys.argv[1:])
```
